1. Dictionary buku digunakan untuk menyimpan data buku seperti judul, penulis, dan tahun terbit.
2. while True digunakan agar menu dapat dijalankan berulang kali sampai pengguna memilih keluar.
3. print() menu digunakan untuk menampilkan pilihan menu yaitu tampilkan, tambah, ubah, hapus, dan keluar.
4. input() digunakan untuk menerima pilihan menu dari pengguna.
5. Pilihan 1 menggunakan for dan .items() untuk menampilkan seluruh key dan value dari dictionary.
6. Pilihan 2 digunakan untuk menambahkan data penerbit ke dalam dictionary.
7. Pilihan 3 digunakan untuk mengubah nama penulis pada dictionary.
8. Pilihan 4 mengecek keberadaan data penerbit, kemudian menghapusnya menggunakan del.
9. Pilihan 5 menggunakan break untuk menghentikan perulangan dan mengakhiri program.
10. else digunakan untuk menampilkan pesan jika pengguna memasukkan pilihan yang tidak tersedia.
11. Bagian akhir program menampilkan kembali seluruh data buku setelah dilakukan perubahan.
